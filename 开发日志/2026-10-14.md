# 开发日志 2026-10-14

本轮只做一件事：把 FR-38（浅色系渐变皮肤）从需求落到能交给亲友看的程度，
并且给它配上**能自己证明自己没坏**的守卫。Core 与 Data 一行没动。

## 一、先说清楚我为什么要在测试里画像素

上一轮结束时的处境：皮肤改完，244 个测试全绿，但我**一次都没看见它长什么样**。
这台机器的窗口置不到前台（`activate_window` 报"could not be made foreground"，
截出来的客户区是一片白），所以"我看过界面"这句话当时是说不出口的——
而一条"界面改好了"的进展如果只能靠我自己看，那它对下一轮的我等于不存在。

于是换了个思路：**渲染不依赖窗口显示**。测试里把主窗口的内容挂到一个固定尺寸的宿主上，
用 `RenderTargetBitmap` 画到内存，再存成 PNG。这样两件事同时成立：
我能真的看见它，而且"画出来了没有"变成一条可以重复跑的断言。

代价是三个坑，都记在这里：

1. **没 Show 的 Window 画不出自己的背景**。`Window.Background` 不在内容的可视树里，
   渲出来四周缺一圈底。解法是把同一支画刷（从 `window.Background` 读，不复制键名）
   挂到宿主 `Border` 上。
2. **把内容从 Window 里摘出来，`DataContext` 就断了**。继承链一断，界面变成没有数据的空壳——
   第一版渲染图里出发/到达框全空、下拉框没有选中项，就是这么来的。
   这一条值得写进日志：静态检查与单元测试都发现不了"我测的是个空壳"，只有图能看出来。
3. **数颜色的门槛不能凭感觉定**。我先把门槛调成一个必然大失败的数，
   把四种视图的真实数字打出来看（前景像素 3.0~3.6 万，窗口底竖线 8~16 种色），再回头定门槛。

## 二、渲染图当场揪出的一个真缺陷：折叠面板的标题变成了一串字面量

浅色档第一张图底部明明白白写着 `Content="{TemplateBinding Header}"`。
原因很低级：`主题.xaml` 里 Expander 模板那行 `Content="…"` 换行时落在了开始标签的 `>` 之后，
于是它不再是属性，而是 ToggleButton 的**元素内容**——XAML 照单全收，把它当字符串画了出来。
编译过、解析过、样式套上过，三层守卫全绿，只有像素看得见。

顺带修的第二处：`{TemplateBinding Header}` 本身也是错的，那层的 TemplatedParent 是 ToggleButton，
它没有 Header 属性。改成 `{Binding Header, RelativeSource={RelativeSource TemplatedParent}}`。

## 三、守卫分三层，每层各挡一种"看起来成功了"

- **静态层**（`ThemeGuardTests` 新增 5 条）：两档色板的渐变键必须一一对应；每个渐变至少两个色标
  （只有一个色标的是假渐变）；方向必须全部纵向同向；正文色与次级色对**所在底的两端分别**过 AA；
  数据区行底渐变两端亮度差压到 ≤0.04；控件边界对底 ≥3:1。
- **模板层**（`SkinRuntimeGuardTests` 前半，28 例）：14 个换肤控件在两档色板下各建一次，
  真的套样式、真的开弹层。挡的是"触发器只在第一次应用模板时才构造"这类错——
  上一轮 DatePicker 把主窗口炸没，编译与静态守卫当时都是绿的。
- **像素层**（同文件后半，8 例）：直达 / 中转 / 报错 / 设置四个界面 × 两档色板，
  判三条：整幅不是空白、窗口底那一列不是纯色、跟底色差得远的像素不能是零。
  每次跑还往 `%TEMP%\rq-skin-render\` 落 8 张 PNG 供人复核。

**三条都做了"种错验证"**（不验证的守卫等于没有守卫）：
把窗口底换成 `Brushes.White` → 报"渐变没画出来"；把内容换成 null → 报"根本没渲染出来"；
把浅色档正文色改成接近底色 → 前景像素从 3.0 万掉到 2.0 万，**没有跌破门槛**。
最后这一条我没修饰：它说明像素层兜不住"某一支笔刷撞色"，那种精度归静态层管
（它能指到具体哪一支刷、哪一端）。像素层只兜"整片一个字都没画出来"。门槛注释里写的就是这个实测数。

## 四、收尾时顺手清掉的三处

- 登录页的窗口底与顶部说明条还在用旧的纯色键 → 改 `渐变_窗口底` / `渐变_提醒底`。
- 进度条填充是纯色 → 新增 `渐变_进度填充`（两档各一支，纵向，与其余渐变同向）。
  轨道**故意留纯色**：轨道再渐变会让人读出"两段进度"的错觉，这个理由写进了色板注释。
- 三个纯色底键改完就没人用了 → 直接删，不留"以后可能用得上"的键。
  现在两档色板各剩 13 支渐变 + 1 支纯色底。
