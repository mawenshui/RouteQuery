# RouteQuery — Windows 列车线路查询助手

一个 **不下单、不碰凭据、只读查询** 的 Windows 桌面应用：输入出发地、目的地和日期，把 12306 官方的直达车次与换乘方案整理成本地可筛选、可比对、可钻取的结果视图，需要买票时一键跳转官方页面。

> 本工具与 12306 官方无任何关联。不采集任何个人信息；查询条件、收藏、历史只存本机。若使用内嵌官方登录页获取换乘数据，会话以 DPAPI 加密存在本机，并提供一键清除。

## 一分钟看懂这个应用

**做**：站点模糊输入 → 选日期 → 查直达（游客可用）→ 可选登录官方页查换乘方案 → 按车型/时段筛选 → 按最快/最早/最便宜排序 → 点开看经停站 → **对买不到票的车次算"多买几站"要花多少钱（上限 1–10 站可设）** → 收藏常用线路 → 跳转官方购票。

**不做**：自实现账密登录、代填验证码、购票、候补、余票自动监控、读取订单/常旅客、**为"多买几站"提供任何自动下单或锁票**、**对中转两段分别扩展**、多设备同步、云端服务。

**三个根本约束**：

1. 12306 没有公开 API。本应用依赖网页端非公开接口，路径与字段随时可能变化。
2. **余票的权威数据列尚未确认**（Q-10）——实测发现两个候选列在同一趟车上互相矛盾。因此凡依赖余票的功能（"只看有票"筛选、余票简摘）在完成逐格比对前不接通。宁可空着一格，也不猜一个看起来正常的数字。
3. **"多买几站"是本项目第一个允许"一次动作 → 十次以上官方请求"的功能**，而它恰好在官方压力最大时被使用。频率约束因此按动作类型分级（基础 ≤3、扩展 ≤10，硬上限 12），并把"能否拿到经停站序"（Q-04）变成了 P0 阻塞项：拿不到就整体退回 V1.1，**不用猜测的邻近站凑候选**。
