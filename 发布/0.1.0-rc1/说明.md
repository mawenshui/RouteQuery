## 验收时请重点自己点这些（自动化没覆盖到的）

1. **"多买几站"完整链路**：需要挑一个**当前买不到票**的车次（自动化跑的那趟京沪线全部有票，入口按 FR-31 不出现）。建议用高峰日或冷门区间。要看的点：候选列表、多买几站与多花多少钱**同一行**、缺价显示"无法计算"而不是 0、点"停止"后已查到的结果还在。
2. **筛选与排序联动**：勾"只看有票"、切车型，确认断网后已加载的结果仍能筛选（不发请求）。
3. **错误文案**：拔网线点查询（应为"连不上网络…然后点重试"+ 重试按钮）、3 秒内连点（应为"稍等几秒再查询"且**不发**第二个请求）。
4. **日期越界**：用"后天"按钮和日历控件确认范围外点不动；改系统日期到 15 天内边缘再查一次。
5. **键盘走通主链路**：只用 Tab / ↑↓ / 回车 / Esc 完成一次查询（NFR-10）。
6. **换一台机器或另一个 Windows 账户**跑一次（SPEC-006 发布前清单要求，模拟亲友环境）。
