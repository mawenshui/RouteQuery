# RouteQuery 使用说明（0.1.0-rc1 验收版）

> 这一版是**给你自己验收用的**，不是发给亲友的版本：中转换乘、常用线路、设置页都还没做。
> 能用的部分列在下面"这一版能做什么"。

## 怎么运行

1. **整个文件夹一起解压**，不要只把 `RouteQuery.exe` 单独拷出来——`Resources/stations.json` 是内置站点表，缺了它每次查询都会提示"内置站点数据读不出来"。
2. 双击 `RouteQuery.exe`。不需要装 .NET，也不需要安装，解压即用。
3. 第一次打开会先弹一句声明，点"确定"进入查询界面。这个提示只出现一次。
4. 如果 Windows 弹出"已保护你的电脑 / 未知发布者"，选"仍要运行"。这个程序没有数字签名（签名要花钱，且对个人分发没有实际意义），源文件在本仓库里可查。

## 这一版能做什么

**查直达车次**
- 出发站、到达站各打几个字就能联想，支持全拼和首字母（输入 `bjn` 能找到北京南）
- 同城不同站会分开列出（北京 / 北京南 / 北京西 是三个选项，不会合并）
- 日期可选范围是今天起 15 天，范围外的日期点不动
- 结果列出：车次、发时、到时、历时、席别余票、最低票价；跨零点到达会标"次日"

**筛和排**
- 按车型（高铁/动车/城际/直达/特快/快速/普客）、出发时段、只看有票、当天到达筛选
- 按最早出发 / 最晚出发 / 历时最短 / 到达最早 / 最低价排序
- 筛选和排序**不再向官方发请求**，是本地内存里做的

**看中途停哪些站**
- 点一趟车的"经停站"，下方列出全部停靠站的站序、到时、发时、停留时长
- 你这次查询的两个站会分别标 ▲（上车站）和 ▼（下车站）

**买不到票时算"多买几站"**
- 对**当前买不到票**的车次，行上会出现"多买几站"按钮
- 它把票面区间往前或往后扩几站，逐站查官方有没有票、票价多少、**要多花多少钱**
- 最多扩几站可以自己设（1–10，默认 3）。开始前会显示"预计约多少秒、要查几个方案"
- 中途点"停止"就停下，已经查到的结果保留
- 算不出差额时写"无法计算"，不会写 0；算出负数会写"价格数据异常"并且不显示那个数字

**跳到官方买票**
- 选中一趟车后点"到 12306 查看"，会用你默认的浏览器打开官方查询页
- 它**不会**替你填表、不会替你下单，站名和日期要你在官方页面里自己输

## 这一版还不能做什么

| 项目 | 状态 |
|---|---|
| 中转换乘方案 | 未做。需要先登录 12306，登录界面（内嵌官方页）在下一版 |
| 常用线路收藏、查询历史 | 未做 |
| 设置页、手动更新站点表入口 | 未做。站点表是安装包里内置的一份，日期显示在窗口左下角 |
| 深色主题 | 未做，只有浅色 |
| 检查更新 | 未做 |
| 学生票 / 儿童票价格 | 不做两套价，只有官方成人票价 |

## 数据是从哪来的

所有车次、余票、票价、经停站都来自 12306 官方查询接口，**只读**。

**取不到就报错，不会用别的方式补一个数给你。** 所以如果某一格显示"官方未给出"或者整屏提示出错，那是真的没拿到数据，不是系统在猜。票价和余票随时在变，最终以你下单时 12306 页面显示的为准。

## 关于查询频率

这个工具刻意做得"慢"一点，为的是不把亲友的 IP 和账号搞进风险名单：

- 两次查询之间至少隔 3 秒，连点会被提示"稍等几秒再查询"
- 一次普通查询最多向官方发 3 个请求
- 一次"多买几站"最多发 12 个请求，并且是一个一个串行发的
- 一天最多 200 次，窗口下方会显示"今日还可查询 N 次"
- 没有任何自动刷新、自动监控余票的功能——每次查询都是你按下去的

## 本机存了哪些东西

全部在这个文件夹：`%LOCALAPPDATA%\RouteQuery\`

| 文件 | 内容 |
|---|---|
| `settings.json` | 你设的"最多扩展站数"、是否已看过首次声明 |
| `endpoints.json` | 官方接口路径的缓存（它会改后缀，缓存一次省一次请求） |
| `logs/query-日期.log` | 出现没预料到的异常时记下的一行，方便你把一句话发给我定位 |

**没有密码、没有验证码、没有 Cookie 明文。** 这个版本根本没有登录能力，所以它拿不到你的账号任何东西。想彻底清空，把这个文件夹删掉即可。

> 两处已知未完成（不影响验收，但先说清楚）：**"今日还可查询 N 次"目前只记在程序内存里**，重开程序会重新计数；每次向官方发了几个请求也**还没有写进日志**。这两项是计划里的独立任务，补上之前请不要把"日额度"当成跨启动的硬保证。

## 出问题先看这里

| 屏幕上写的 | 你该做什么 |
|---|---|
| 连不上网络 | 检查这台机器的网络，然后点重试 |
| 官方响应有点慢 | 过一会儿再试，不用反复点 |
| 官方查询暂时不可用 | 等几分钟再试。**这不是你的网络问题，反复点没有用** |
| 稍等几秒再查询 | 点太快了，等 3 秒 |
| 官方数据格式变了 | 截图发给我，这需要发新版，你这边重试不会好 |
| 内置站点数据读不出来 | 你多半只拷了 exe，把 `Resources` 文件夹一起放回来 |
| 官方没有返回这一项数据 | 等一会儿再试，或者直接到 12306 官网查这一项 |

## 系统要求

64 位 Windows 10 或 11。Windows 7 / 8 不支持，32 位系统不支持。

（Windows 10 实机验证还没做过——如果亲友里有 Win10 的机器，第一次运行请留意能不能正常打开。）
