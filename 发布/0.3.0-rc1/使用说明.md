# RouteQuery 使用说明（0.3.0-rc1 验收版）

> 这一版仍是**给你自己验收用的**。V1 的功能在这里已经全部实现完了，
> 但有一批"必须用眼睛看"的判据我没能自己确认（原因写在最后一节），需要你解锁机器逐条走一遍。

## 怎么运行

1. **整个文件夹一起解压**，不要只把 `RouteQuery.exe` 单独拷出来——`Resources/stations.json` 是内置站点表，缺了它每次查询都会提示"内置站点数据读不出来"。
2. 双击 `RouteQuery.exe`。不需要装 .NET，也不需要安装，解压即用。
   **第一次打开会慢**（约 10~30 秒，看机器）：程序是自包含单文件，第一次运行要把运行时解到临时目录。之后就快了。
3. 第一次打开会先弹一句声明，点"确定"进入查询界面。这个提示只出现一次。
4. 如果 Windows 弹出"已保护你的电脑 / 未知发布者"，选"仍要运行"。这个程序没有数字签名（签名要花钱，且对个人分发没有实际意义），源文件在本仓库里可查。

## 这一版能做什么

**查直达车次**
- 出发站、到达站各打几个字就能联想，支持全拼和首字母（输入 `bjn` 能找到北京南）
- 同城不同站会分开列出（北京 / 北京南 / 北京西 是三个选项，不会合并）
- 日期可选范围是今天起 15 天，范围外的日期点不动
- 结果列出：车次、发时、到时、历时、席别余票、最低票价；跨零点到达会标"次日"

**筛和排**
- 按车型、出发时段、只看有票、当天到达筛选
- 按最早出发 / 最晚出发 / 历时最短 / 到达最早 / 最低价排序
- 筛选和排序**不再向官方发请求**，是本地内存里做的

**看中途停哪些站**
- 点一趟车的"经停站"，下方列出全部停靠站的站序、到时、发时、停留时长
- 你这次查询的两个站会分别标 ▲（上车站）和 ▼（下车站）

**中转换乘（这一版能用）**
- 先登录（方法见下一节），再在中转页签点"查换乘方案"
- 给出官方推荐的换乘方案：两段车次、换乘站、候车多久、全程多久、每段席别余票
- **没有票价**。官方在这个接口里不给票价，所以那一格写"票价官方未给出"，也不按价格排序——
  一个看起来正常的假价格，比留空危险得多
- 官方给 0 个方案时会明说"官方没有"，和"我们解不出来"是两句不同的话

**收藏与历史**
- 左下角"常用线路"：存下当前这一程（最多 20 条），双击填好条件——**日期要重新确认**，它故意不存日期
- 每条收藏右边有"删除"，删完会在下方写"已删除收藏：X"
- "最近查询"自动记最近 30 条，双击回填，可一键清空

**买不到票时算"多买几站"**
- 对**当前买不到票**的车次，行上会出现"多买几站"按钮
- 把票面区间往前或往后扩几站，逐站查官方有没有票、票价多少、**要多花多少钱**
- 最多扩几站可以自己设（1–10，默认 3）。开始前会显示"预计约多少秒、要查几个方案"
- 中途点"停止"就停下，已查到的结果保留
- 这趟车在你查的区间已经是全程票时，会明说"前后都没有更多站可买"，不会显示"已完成 0 / 0"
- 算不出差额时写"无法计算"，不会写 0；算出负数会写"价格数据异常"并且不显示那个数字

**起售时间（这一版新加）**
- 选中一趟车后，下方详情区标题会写"10 月 28 日 08:00 起售"，或者"已过起售时间"
- 官方没给这个信息的车，这一行**整行不出现**
- 它**不会到点提醒你**——那需要程序定时自己发请求，是这个工具明确不做的事

**跳到官方买票**
- 选中一趟车后点"到 12306 查看"，用你默认的浏览器打开官方查询页
- 它**不会**替你填表、不会替你下单，站名和日期要在官方页面里自己输

**外观（这一版新加）**
- 设置页可以选 **跟随系统 / 浅色 / 深色**，点一下就换，不用重启。默认跟随系统
- 跟随系统只在打开程序和手动切换时读一次 Windows 的设置，程序里没有定时器

**检查更新（这一版新加）**
- 启动时向 GitHub 问一次"最新版本号"，比当前版本新才在窗口右下角弱弱地提一句，点一下用浏览器打开发布页
- 不占你的官方查询额度，不带任何你的信息，**断网或问不到就什么都不说**
- 设置页"更新"里可以关掉；关掉后不再有这次出站

## 关于查询频率

这个工具刻意做得"慢"一点，为的是不把亲友的 IP 和账号搞进风险名单：

- 两次查询之间至少隔 3 秒，连点会被提示"稍等几秒再查询"
- 一次普通查询最多向官方发 3 个请求；一次"多买几站"最多 12 个，且串行发
- 一天最多 200 次（登录后 100 次），左下角显示"今日还可查询 N 次"。这个计数**存盘**，重开程序接着算
- 没有任何自动刷新、自动监控余票的功能——每次查询都是你按下去的

## 登录

中转页签里点"登录 12306"，弹出内嵌的官方页面。**账号、密码、验证码都由你在那个页面里自己输入**——
本工具不接收它们，代码里也没有任何能接收它们的地方。登录完成后点"我登录好了"，它才去取官方容器给出的登录状态。

它刻意**不自动判断"你登录成功了"**：官方那个标志字段没有权威依据，猜一个就等于把看不见的判断塞进凭据路径。
所以取到之后界面写的是"已取到登录状态（尚未向官方验证）"。真正用它取数时如果官方不认，
会自动清掉本地副本并提示你重新登录。

设置页的"退出并清除登录状态"会把本机副本和内嵌页面缓存一起清掉。

> **在别人电脑上用过之后，请一定点一次"退出并清除登录状态"。**
>
> 一处诚实的局限：登录状态用 Windows 自带的 DPAPI（当前用户范围）加密存在你自己的用户目录。
> 它防的是"文件被拷走、被同步盘带走、被别的账户读到"；**它不防"已经有程序以你的身份在这台机器上运行"**。

## 这台机器上没装 WebView2 怎么办

登录需要 "Microsoft Edge WebView2 Runtime"，较旧的 Windows 10 可能没有。
没有时登录窗口会直接告诉你，并且**不影响其它任何功能**——直达、经停站、多买几站、收藏历史照常。

> 已实测：开发机（Windows 11）上登录窗口能正常打开官方页面。纯净 Windows 10 仍未验证。

## 本机存了哪些东西

全部在 `%LOCALAPPDATA%\RouteQuery\`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 最多扩展站数、是否看过首次声明、是否检查更新、主题档位 |
| `routes.json` | 常用线路收藏 |
| `history.json` | 最近 30 条查询 |
| `session.protected` | 登录状态（DPAPI 密文，只有你这个 Windows 账户能解） |
| `webview2/` | 内嵌登录页自己的缓存 |
| `endpoints.json` | 官方接口路径的缓存（它会改后缀，缓存一次省一次请求） |
| `daily.json` | 当天已发请求数（所以额度不能靠重启刷） |
| `logs/query-日期.log` | 每个官方请求一行，加异常记录。你说"查不出来了"时，把当天这个文件发我就够定位 |

**没有密码、没有验证码、没有 Cookie 明文。** 想彻底清空，删掉这个文件夹即可，或设置页点"清空本机数据"。

## 数据是从哪来的

所有车次、余票、票价、经停站、换乘方案都来自 12306 官方查询接口，**只读**。
**取不到就报错，不会用别的方式补一个数给你。** 所以某一格写"官方未给出"或整屏提示出错时，那是真没拿到，不是系统在猜。
票价和余票随时在变，最终以你下单时 12306 页面显示的为准。界面上的价格是**成人票面价**；
学生票、儿童票按官方规则算，这里不算——官方给的第二条价格含义没确认，标成"儿童票"就是拿猜测当数据。

## 出问题先看这里

| 屏幕上写的 | 你该做什么 |
|---|---|
| 连不上网络 / 官方暂时不可用 | 过几分钟再试。反复快点只会让情况更糟；这不是"换姿势重试"能解决的 |
| 官方不认这份登录状态，已清除 | 重新登录一次即可 |
| 今日额度已用完 | 等明天，或者少开几个查询。这个上限是故意设的 |
| 票价官方未给出 | 正常。那个接口确实不给票价，去官方页面看 |
| 内置站点数据读不出来 | 你只拷了 exe。把 `Resources` 文件夹一起放回去 |
| 这趟车在你查的区间已经是全程票了 | 正常提示，不是出错——这趟车前后没有更多站可以买了 |
