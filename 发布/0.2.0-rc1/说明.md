## 验收时请重点自己点这些

1. **登录 → 拿一份 `lcQuery` 样本**。这是解开 TASK-31 的唯一钥匙：登录后点"我登录好了"，然后告诉我，我来把响应的**字段名与结构**（不含任何凭据）记成 `测试/接口样本/` 里的一份样本，解析层照它补。
2. **域名白名单**：在登录页里点任意一个跳到非 `*.12306.cn` 的链接，应看到红字"已阻止跳转到非官方站点：<主机名>"且页面不动。
3. **退出并清除**：登录后点"退出并清除登录状态"，确认 `session.protected` 消失、`webview2/` 目录被删。
4. **码表更新**：设置页点"更新站点数据"，应提示"已取到新的站点数据…关掉重开生效"；中途拔网线应提示保留旧数据且查询照常。
5. **多买几站完整链路**（rc1 遗留）：挑一个买不到票的车次，看候选、金额同行、"无法计算"、点停止保留结果。
6. **只用键盘**走完一次查询（Tab / ↑↓ / 回车 / Esc）。
7. 换一台机器或另一个 Windows 账户跑一次（SPEC-006 发布前清单要求）。
