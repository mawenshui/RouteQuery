## 这一版改了什么（外观，FR-38）

- **两档色板各 13 支纵向渐变**：窗口底、内容底、行底、徽标底、输入底、弹层底、页签底、页签选中底、
  提醒底、按钮底、按钮按下底、错误底，外加进度条填充。方向全部纵向且同向，由守卫强制。
- **对比度是算出来的，不是看着定的**：正文与次级文字对其所在底的**渐变两端分别**过 WCAG AA
  （正文 ≥4.5:1、大字与图形边界 ≥3:1）；数据区行底两端亮度差压到 ≤0.04，防止表格读起来晃。
- **重写了以前没重写的系统控件模板**：`ComboBox`（含可编辑框与弹层）、`DatePicker`（含日历浮层）、
  `ScrollBar`（横竖两套）、`TabItem`、`Button`（四态，禁用不靠透明度糊掉文字）、`TextBox`、`GroupBox`、
  `Expander`、`RadioButton`、`ToolTip`、`Menu` 等——样式字典里现在 22 类隐式样式、16 个 `ControlTemplate`。
  **K-10 因此关闭**：深色档下不再出现"深色窗口里嵌一块浅色系统控件"。
- **语义没有被稀释**：余票三态与"官方未给出"仍然由**文字**区分，不是只靠颜色；
  错误横幅的浅红底与白字配成一对键，浅色档下也是可读的深字。
- 设置页与内嵌登录页的底色、顶部提示条一起换成渐变。
- 进度条轨道**刻意留纯色**（唯一一支纯色底键）：轨道自身再渐变会让人读出"两段进度"的错觉。

**没改的**：列顺序、任何措辞、任何数据取法、字号、布局结构、`Core/` 与 `Data/` 全部零改动。

## 请你重点看这几条（我没法自己看到）

前四条是复走清单本来就欠的，后三条是这一版新增的：

1. **中转两段各自展开**：需先登录。看四件事——两段能否同时展开且各看各的；按钮文案是否从"经停站"变成
   "收起经停"；段标题那行"车次 · 区间 · 该段日期"在卡片里挤不挤；一段报错时另一段是否完全不受牵连。
2. **收藏删除的真实点击行为**与收藏满 20 条时的提示（我没有替你点，那会真删掉你存的那条）。
3. **全程票场景**：点"开始扩展"应显示专门说明，不是"已完成 0 / 0"。
4. **关掉检查更新后**重启，抓包应看到零非官方出站。
5. **125% / 150% 缩放下浅色与深色各走查一次**（FR-35 验收② + FR-38 验收⑤）——**这一条最可能出问题**：
   渐变皮肤重画了控件边框与内边距，缩放后哪一行挤了、哪个下拉框的字被裁了，只有真机能看出来。
6. **真实中文文案下的外观**：测试里渲染用的是假文案替身（回显键名），所以"字有没有换行、
   有没有截断、按钮文字会不会撑破"这三件事我一张图都没验到。
7. **登录那一屏**：内嵌官方页的窗口底色与顶部提示条也换成了渐变，但 WebView2 在测试里渲不出来，
   需要人眼看一次"浅色提示条上的字读不读得清"。

另外这几条只能由你本人做：亲友无指导首查（TC-F9）、拔网线（TC-B7）、
与官方页面逐格比对 Δ 金额（TC-D9）、干净 Windows 账户装包（TC-F8）。

## 已知问题（延续 + 新增）

- **K-03** 三列席别的中文名官方从未给出，界面照实写"未确认席别"。
- **K-04 / Q-12** 弃用区间与提前下车的官方口径未核实，界面一律中性表述。
- **K-05** 未在纯净 Windows 10 上实测。
- **K-07** 首次启动 10~30 秒（单文件自包含解压）。用例 TC-F6 已按此把判据收窄为
  "第二次及以后启动 ≤2 秒"——代价是"第一次变慢"这类回归从此抓不到，首次耗时改由日志记录。
- **K-09** 检查更新的端到端判据仍验不了：GitHub 的 `releases/latest` 按定义排除预发布，
  而 rc→rc 我们又故意不当成升级。**打 `v1.0.0` 时不要勾 prerelease**。
- ~~**K-10**~~ **本包关闭**：下拉、日历、滚动条、页签的模板已重写，两档都跟着主题走。
  仍归系统画的是**窗口标题栏**——要改它得引 `WindowChrome` 自绘，FR-38 的模板清单里没有它。
- **新增：外观的肉眼验收一条都没过**。三档主题 × 三档缩放（TASK-56）没跑；真实文案下的换行与截断没验；
  登录页那一屏渲不出来。测试能数像素，但**像素对了不等于好看看**。
- **`same_station` / `isOutStation` 语义仍未确认**，界面不据此断言"需换车站/需出站"。
- **打包仍是手工**（`publish → 转文本 → 压包 → 算校验和`）。两份 txt 由 md 生成这一步已经稳定两轮，
  但整条链路还没一键化——rc4 出过一次"包内说明停在上一版"的事故，值得排进 V2 第一件事。
