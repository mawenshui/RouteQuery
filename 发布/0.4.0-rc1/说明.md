## 这一版改了什么（第 9 轮，FR-39 ~ FR-45）

- **顶部菜单栏**（文件 / 视图 / 主题 / 帮助）取代底部状态栏；站点数据日期旁直接给"更新站点数据"，
  更新成功弹重启框（立即重启＝先起新进程再退当前，绝不静默重启）。
- **两条分隔器**：侧栏宽度、详情区高度可拖；侧栏 / 筛选行 / 详情区 / 顶部信息条可单独隐藏。
  显隐与尺寸**不持久化**（FR-22 的"不做多余开关"仍然成立）。
- **常驻表头**：画在 `ScrollViewer` 外面，纵向滚动时不动；点表头改的是排序下拉那一份状态。
  这条同时**补掉 FR-12 从 v1.0 就写着却没人做的"点击列头排序"**。
- **选中即取经停**：每动作 ≤1 个 `API-04` 请求、同一趟取过不重复取、换选作废在途、
  详情区隐藏时干脆不取；行上的"经停站"按钮改挂行自己的命令，未选中的行也能出数。
  "今日还可查询 N 次"随之从加载态提升为常驻。**没有任何去抖定时器。**
- **整块可展开**：四个非编辑下拉框与日期框点哪都开；可编辑框热区退回箭头那一格（不能挡住打字）。
- **站名唯一命中自动选定**：只认"站名完全相同"与"候选恰好一条"，歧义一律不选。
- **浅色档加深**：两档键集合仍一致；行底两端亮度差第一版算出 0.044 被 FR-38 判红，
  收窄到 0.038 才通过——**没有去动门槛**。

## 请你重点看这几条（我没法自己看到）

前四条是复走清单本来就欠的，后五条是这一版新增的表面：

1. **中转两段各自展开**：需先登录。两段能否同时展开各看各的；段标题那行"车次 · 区间 · 该段日期"挤不挤；一段报错时另一段是否不受牵连。
2. **收藏删除的真实点击行为**与收藏满 20 条时的提示。
3. **全程票场景**：点"开始扩展"应显示专门说明，不是"已完成 0 / 0"。
4. **关掉检查更新后**重启，抓包应看到零非官方出站。
5. **125% / 150% 缩放**下浅色与深色各走查一次——**本轮最可能出问题的地方**：
   菜单、表头、分隔器都是新画的面，缩放后哪一处挤了或裁了只有真机能看出来。
6. **真实中文文案下的外观**：测试里渲染用的是假文案替身（回显键名），换行与截断一张图都没验到。
7. **点表头排序**：点"出发"两次应在"最早出发 / 最晚出发"之间来回切，且与排序下拉选同一键结果一致。
8. **选中即取的额度感受**：连着点五六行看看"今日还可查询 N 次"掉得快不快、被限制时提示读不读得懂。
   如果觉得"点一下就想看经停"太费额度，这条可以退回按钮式——需要你说了算。
9. **自动匹配会不会选错**：试试"北京""衡水""bjn"三种写法，看它选定的站是不是你以为的那个。

另外这几条只能由你本人做：亲友无指导首查（TC-F9）、拔网线（TC-B7）、
与官方页面逐格比对 Δ 金额（TC-D9）、干净 Windows 账户装包（TC-F8）。
