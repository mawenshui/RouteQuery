> 本文件面向**使用者（亲友）**，不面向开发者。写作规则见 [SPEC-006 第五节](../规范/版本与发布规范.md)：

## v1.0.0（待发布）

**这是第一个版本。** 它能做这些事：

**查票**
- 输入出发站和到达站（打几个字就能联想，支持拼音），选日期，点查询
- 一次同时给出直达车次和官方换乘方案（换乘需要先登录 12306 账号）
- 显示每趟车的发时、到时、历时、各席别余票和票价；夜车会标"次日"

**挑票**
- 按车型（高铁/动车/普速）、出发时段、席别筛选；可以只看还有票的
- 按最早出发 / 历时最短 / 到达最早 / 最低价排序
- 点开车次能看它中途停哪些站、几点到
- 换乘方案的两段也各自能点开看停哪些站，两段各看各的，能对着读

**买不到票的时候**
- 对买不到的车次点"多买几站"，它会算出往前多坐几站或往后多坐几站分别还有没有票、**要多花多少钱**
- 最多能多买几站可以自己设（1 到 10 站，默认 3 站）；查的过程中随时能停下来，已经查到的结果不会丢

**记住常用线路**
- 把常走的线路存下来，下次一键重查（日期每次重新确认，避免存了过期日期）
- 自动记住最近 30 次查询

**几点需要知道**
- 本工具**不是官方**，只能查，不能买。看到合适的车次请点"到官方查看"，在 12306 完成登录和付款
- 应用不收集任何个人信息，查询记录只存在这台电脑上
- 如果用了登录功能，**在别人的电脑上用完一定要点"清除登录状态"**（状态栏就有）
- 如果某天开始查不出东西、提示"官方数据格式有变化"，那是官方改了，请找我要新版本，重试没有用

## 0.3.0-rc5（2026-10-14，**亲友试用版**）

**这一版只动了"长什么样"，没动"查什么、怎么查"。** 所有车次、余票、票价、经停站、换乘方案的来源和算法与上一版完全一样。

- 整个界面换成一套**浅色系渐变**外观：卡片、按钮、输入框、下拉、日期框、页签、滚动条、弹层都带一层很浅的上下渐变。
- 控件边框加深，"这里能填东西"看得出来；文字与数据**一个措辞都没改**。
- 深色档补齐了以前没做的系统控件：下拉框、日期弹层与日历、滚动条、页签现在都跟着主题走，
  不再出现"深色窗口里嵌一块浅色系统控件"。
- 设置页与登录页的底色、顶部提示条一起换。

**这一版没做完的事**：需要有人对着屏幕看的验收项一条都还没做，125% / 150% 缩放一次没实测。
所以它是**试用件**——请看外观与顺手程度，别拿它显示的数字直接决定买哪趟票。
你反馈的"哪个字看不清、哪个框挤成一团"就是这一版最想要的东西。

## 0.4.0-rc1（2026-10-14，**亲友试用版**）

**这一版全部是"用起来顺不顺手"的改动。** 车次、余票、票价、经停站、换乘方案的来源和算法与上一版完全一样，
界面上一处措辞、一个数字都没改。

- 车次列表**加了一行表头**，往下翻时表头不动；**点表头可以排序**，点"出发"再点一次换成"最晚出发"。
- **点一行车次，下面直接列出它停哪些站**，不用再点"经停站"。没选中的行点那个按钮也照样出这一趟的经停。
  同一趟来回点不会重复向官方取数，不白花你的查询次数。
- **顶部多了一排菜单**（文件 / 视图 / 主题 / 帮助）。原来在窗口最底下那行字（站点数据日期、当前状态、
  "本工具非官方"）都移到顶上来了。**站点日期旁边就是"更新站点数据"按钮**，不用先进设置页；
  更新完会弹窗提醒重启，因为不重启用的还是旧数据。
- **下拉框、日期框点哪里都能展开**，不再只有右边那个小箭头能点。
- **打字打对了不用再点一下**：输入能唯一对上车站的写法（比如"衡水"）就直接能查。
  有歧义时（"北京"能对上北京、北京南、北京西）**仍然要你从联想里点一条**——
  替你猜一个站去查，结果表看起来完全正常、却是按另一个站查出来的，这种错最坑人。
- **侧栏、筛选行、下方详情区都能拖着改大小，也能单独藏起来**（在"视图"菜单里勾）。
  藏起来的东西重启就会回来，不会把你下次打开的界面搞陌生。
- **浅色配色加深了一档**：层次拉开了、边框看得出来，字还是原来的字；深色档同步复核过。
- 窗口底部不再有一条状态栏占地方。"今日还可查询多少次"现在**一直显示**在顶部——
  因为点一行就会取一次经停，你得随时看得见自己在花什么。

**这一版没做完的事**：需要有人对着屏幕看的检查还没做完，125% / 150% 缩放一次没实测。
所以它是**试用件**——请看界面顺不顺眼、操作跟不跟手，**别拿它显示的数字直接决定买哪趟票**。
"哪个字看不清、哪个框挤成一团、哪一步点下去没反应"就是这一版最想要的反馈。

## 0.4.0-rc2（2026-10-14，**亲友试用版**）

**这一版里有一条是"以前显示的数不对"，请先看第二条。**

- 每趟车的席别和票价摆全了：官方给几个席别就列几个，每个席别带上自己的余票和票价，不再只挑前三行。
- **无座和优选一等座以前一直显示"官方未给出票价"，而官方页面上是有价的**。查下去发现不是界面少画了几行，
  而是**价格对到了错的席别上**：普速车次里硬卧和软卧的代号记反了，于是有一趟显示"硬卧 102.5 元、
  软卧 67.5 元"——一个比软卧还贵的硬卧，摆在界面上和真数据一模一样。现在按官方页面自己那份席别对照表
  整张重排过。**如果你用过上一版看硬卧/软卧的价，请以这一版为准。**
- **"这个日期没有直达车次"改在车次列表正中间显示**，不再只是窗口最上面一行小字；
  收藏存满时的提示也搬进收藏那一栏并换成醒目底色。
- **"今日还可查询 N 次"挪到查询按钮左边，"共 x 趟车"挪到表头右上方**，窗口最上面那行不再重复这两句。
- **"设置"从"帮助"里提出来单独一项**，并且全站只有这一个入口。
- 顶部菜单变成五组：文件 / 视图 / 主题 / 设置 / 帮助。

**这一版没做完的事**：需要有人对着屏幕看的检查仍然没做完（三档缩放、真实文案下的换行与截断、
收藏满的那一眼）。所以它还是**试用件**——请看界面顺不顺眼、数字对不对路，
**别拿它显示的价格直接决定买哪趟票**，下单前在官方页面再核一次。

## 尚未发布的功能（别期待，也别催）

| 功能 | 为什么还没做 |
|---|---|
| 余票自动提醒 | 需要定时反复查询官方接口，会把工具推向"抢票辅助"，且账号/IP 有被限制的风险。要做之前得先修订使用规则 |
| 我的订单、常旅客 | 技术上已经具备登录能力，但读这些属于"账号代理"而不是"查询工具"，需要单独评估 |
| 导出行程、多语言 | 还没有明确的使用者提出需要 |

> **行程对比已经排进下一个版本**（两趟车并排比时间、历时、余票和票价）。
> 它只把已经查到的结果摆在一起看，不会为了凑数据多发请求。

## 发布物构成（每次发版都要有）

```
RouteQuery-<版本号>-win-x64.zip
├── RouteQuery.exe          双击即用，不需要装任何运行环境
├── 使用说明.txt             首次运行注意事项 · 如何更新站点数据 · 如何反馈问题 ·
│                            登录风险提示与"他人电脑请用后清除登录状态"
└── 变更日志.txt             本文件对应版本那一段的纯文本版
```

`发布/<版本号>/说明.md` 只记录元信息（文件名、SHA-256、发布日期、已知问题），二进制不进仓库。
