# RouteQuery 使用说明（0.4.0-rc3）

一个"查 12306 有没有票、几点走、要多少钱"的小工具。**它不下单、不占座、不候补**，也不会在你不在的时候自己发请求。

> ## 先读这一段：这一版仍然是**试用件**，不是正式版
>
> **请只拿它看看界面顺不顺眼、功能对不对路，不要根据它显示的时间或价格直接决定买哪趟票。**
> 真要下单，请在 12306 官方页面再核一次——界面显示的和官方实际卖的可能在这一分钟里不一样。
>
> 这一版为什么还是试用件，说法要准确一点：**"需要有人对着屏幕看"的那批检查这一轮已经做完了**
> （三档主题在 100% / 125% / 150% 下各走过一遍，收藏删除、全程票提示、关掉检查更新后是否真的不联网、
> 启动有没有白屏、只用键盘能不能选到车站，都看过了，都正常）。
> 卡住正式版的是另一件事：**这一段时间新加的那些功能还没有一张对应的验收清单**，
> 所以"每一项都验过了"这句话现在说不出口。这不是"没人看过"，是"没有清单可勾"。
>
> 用的时候哪里不对，把当天那个日志文件发我就够定位了（位置在"本机存了哪些东西"那一节）。
> **不用截图，也不用你描述**，日志里都有。
>
> 正式版号是 `v1.0.0`，等那张清单补出来、走完再出。你现在的反馈就是把它推过去的东西。

## 怎么装

解压后**双击 `RouteQuery.exe` 就行**。包里另有 `使用说明.txt` 和 `变更日志.txt` 两份纯文本，
看不看都不影响运行——它们是给"不打算回仓库翻"的人准备的。

不需要装 .NET，不需要"安装"，也不需要拷贝别的文件夹：站点表已经打进 exe 里面了。
（旧版要在 exe 旁边放一个 `Resources/stations.json`，漏拷就会一直报"读不出站点数据"。从 rc3 起不再有那个文件，也不再会有那种报错。）

第一次打开会慢一些（约 10~30 秒，看机器）：程序是单文件自包含的，第一次运行要把运行时解到临时目录。之后就快了。
（这一句是提前打招呼用的。实测这台机器上冷启动不到 1 秒，但**你第一次拿到这个文件时杀毒软件要扫一遍**，
那个开销我测不到，所以这句不删。）

第一次打开还会弹一句声明，点"确定"进入。**不接受声明就不会进入查询界面**，这是有意的。

如果 Windows 提示"已保护你的电脑 / 未知发布者"，选"仍要运行"——这个程序没有数字签名（签名要花钱，对个人分发没有实际意义），源码在本仓库里可查。

## 这一版（0.4.0-rc3）比 rc2 多了什么

**只有一件，但属于"以前显示的数不够准"。**

- **余票那一格现在写"还剩几张"，不再一律写"有票"。** 把这一版和 12306 官方页面一格一格对着比才发现：
  官方那格写"商务座 7"，我们写"商务座 有"。数字其实一路都取到了，是最后画到界面上那一步被抹平成"有"的。
  这有实际影响——**"只剩 5 张"和"多到数不过来"在界面上变成同一句话**，而你可能正是要靠它决定要不要现在下单。
  现在官方给数字就照数字显示；官方自己写"有"（那是 20 张以上）才显示"有"。

## rc2 相比 rc1 多了什么（没装 rc2 的话看这段）

- **每趟车的席别和票价摆全了**。以前一行只挑三个席别显示，现在官方给几个就列几个：
  商务座、优选一等座、一等座、二等座、无座各占一行，各带自己的余票和票价。
- **无座和优选一等座终于有价了**。上一版这两格永远写"官方未给出票价"，而官方页面上明明写着
  "无座票价661元"。查下去发现不是少画了几行，是**价格对错了席别**：
  普速那几档里，硬卧和软卧的代号被记反了——于是有一趟车显示"硬卧 102.5 元、软卧 67.5 元"，
  **一个比软卧还贵的硬卧**。它摆在界面上和真数据长得一模一样，谁也不会多看一眼。
  现在按官方页面自己那份对照表整张重排过，无座也照官方口径给出价格。
  这一条属于"以前显示的数是错的"，如果你用过 rc1 看过硬卧/软卧的价，请以 rc2 及以后为准。
- **"没有直达车次"这句话搬到车次列表正中间**，不再只是窗口最上面一行小字。
  收藏存满 20 条时的提示也搬进收藏那一栏，用醒目的底色，不再缩在左下角。
- **"今日还可查询 N 次"挪到查询按钮左边**（它约束的就是"点查询"这个动作）；
  **"共 x 趟车"挪到表头右上方**（它说的是这张表有几行）。窗口最上面那行不再重复这两句，
  只说"查询完成"或出错原因。
- **"设置"从"帮助"菜单里提出来，单独一排一项**，而且全站只有这一个入口——
  两个入口迟早会长出两种行为。
- 顶部菜单变成五组：文件 / 视图 / 主题 / **设置** / 帮助。
- **查不到换乘方案时会给一句话**：官方偶尔不给数据，以前是什么都不出，
  现在老实说"官方没有返回这一项数据，等一会儿再试，或到 12306 官网查"。

## 能做什么

**查直达车次**
- 出发站、到达站各打几个字就联想，支持全拼和首字母（输入 `bjn` 能找到北京南）
- **打的名字刚好只有一个站对得上，它就直接替你选上**（打"北京南"不用再点一下）；
  对上好几个站（打"北京"会出来北京、北京南、北京西）时**绝不替你猜**，一定要你点一条——
  替你挑一个并据此向官方发查询，等于把一次猜测定格成一张看起来完全正常的结果
- 同城不同站分开列（北京 / 北京南 / 北京西 是三个选项，不合并）
- 日期范围是今天起 15 天，范围外点不动
- 结果列出：车次、发时、到时、历时、席别余票、最低票价；跨零点到达会标"次日"
- 界面上的价格是**成人票面价**。学生票、儿童票按官方规则算，这里不算，也只说明这一点——
  官方在这一行里没有给出学生/儿童价的字段，拿成人价打个折猜出来就是拿猜测当数据

**筛和排**：按车型、出发时段、只看有票、当天到达筛选；按最早出发 / 最晚出发 / 历时最短 / 到达最早 / 最低价排序。
**点表头也能排序**，点一下表头和用上面那个下拉选的是同一件事。**筛选和排序不再向官方发请求**，都在本地内存里做。

**看中途停哪些站**：点一趟车的"经停站"，下方列出全部停靠站的站序、到时、发时、停留时长；你查的那两个站分别标 ▲（上车站）和 ▼（下车站）。
现在**选中一趟车就直接出经停**，不用再点一下按钮。

**起售时间**：选中一趟车后，下方详情区标题会写"10 月 28 日 08:00 起售"，或者"已过起售时间"。
官方没给这个信息的车，这一行整行不出现。**它不会到点提醒你**——那需要程序定时自己发请求，是这个工具明确不做的事。

**中转换乘**：先登录（见下一节），再在"中转换乘"页签点"查换乘方案"。
给出官方推荐的换乘方案：两段车次、换乘站、候车多久、全程多久、每段席别余票，**每段还能各自点开看它停哪些站**。
**没有票价**——官方在这个接口里不给票价，所以那一格写"票价官方未给出"，也不按价格排序。
留一个空白格会被读成"免费"或"0 元"，那是会让人做错决定的错。

**买不到票时算"多买几站"**：对当前买不到票的车次，行上会出现"多买几站"。
它把票面区间往前或往后扩几站，逐站查官方有没有票、票价多少、**要多花多少钱**。
最多扩几站可以自己设（1–10，默认 3），开始前会显示"预计约多少秒、要查几个方案"，中途点"停止"就停、已查到的保留。
这趟车在你查的区间已经是全程票时，会明说"前后都没有更多站可买"，也不会发任何请求。
算不出差额时写"无法计算"，不会写 0；算出负数会写"价格数据异常"并且不显示那个数字。
**换乘方案的两段不提供这个入口**（会做乘积级的请求放大，明确不做）。

**收藏与历史**：左下角"常用线路"存当前这一程（最多 20 条），双击填好条件——**日期要重新确认**，它故意不存日期；每条右边有"删除"。
下面"最近查询"自动记最近 30 条，双击回填，可一键清空。

**外观**：设置页可选 跟随系统 / 浅色 / 深色，点一下就换、不用重启，默认跟随系统。
三档下下拉框、日期弹层与日历、滚动条、页签都会跟着一起换，不再有"深色窗口里嵌一块浅色系统控件"那种割裂。
顶部"主题"菜单里也是同一档，两边不会不一致。

**面板可以自己挪**：中间那条分隔线能拖动，改左右两栏和上下两块的宽窄；
"视图"菜单里能把侧栏、筛选条、详情区单独收起来，看窄一点的地方更清爽。

**检查更新**：启动时向 GitHub 问一次"最新版本号"，比当前版本新才在窗口右下角弱弱提一句，点一下用浏览器打开发布页。
不占你的官方查询额度、不带任何你的信息、断网或问不到就什么都不说。设置页"更新"里可以关掉。
（注意：GitHub 那个"最新版本"的问法**按定义看不到预发布件**，所以 rc 之间不会互相提示——这不是坏了。）

**跳到官方买票**：选中一趟车后点"到 12306 查看"，用你默认浏览器打开官方查询页。
它**不会**替你填表、不会替你下单，站名和日期要在官方页面里自己输（官方那个页面能带参数的地址形态没核实过，拼一个猜出来的链接等于给你一个可能打不开的东西）。

## 登录

中转页签里点"登录 12306"，弹出内嵌的**官方页面**。**账号、密码、验证码都由你在那个页面里自己输入**——
本工具不接收它们，代码里也没有任何能接收它们的地方。登录完成后点"我登录好了"，它才去取官方容器给出的登录状态。

它刻意**不自动判断"你登录成功了"**：官方那个标志字段没有权威依据，猜一个就等于把看不见的判断塞进凭据路径。
所以取到之后界面写的是"已取到登录状态（尚未向官方验证）"。真用它取数时如果官方不认，会自动清掉本地副本并提示重新登录。

> **在别人电脑上用过之后，请一定点一次设置页的"退出并清除登录状态"**——它会把本机副本和内嵌页面缓存一起清掉。
>
> 一处诚实的局限：登录状态用 Windows 自带的 DPAPI（当前用户范围）加密存在你自己的用户目录。
> 它防的是"文件被拷走、被同步盘带走、被别的账户读到"；**它不防"已经有程序以你的身份在这台机器上运行"**。

## 关于查询频率

这个工具刻意做得"慢"一点，为的是不把亲友的 IP 和账号搞进风险名单：

- 两次查询之间至少隔 3 秒，连点会提示"稍等几秒再查询"
- 一次普通查询最多向官方发 3 个请求；一次"多买几站"最多 12 个，且串行发
- 看一段的经停站 = 1 个请求；收起再点开不算第二次
- 一天最多 200 次（登录后 100 次），查询按钮左边显示"今日还可查询 N 次"。这个计数**存盘**，重开程序接着算，重启刷不出额度
- 没有任何自动刷新、自动监控余票的功能——每次查询都是你按下去的

## 站点表（码表）是什么、怎么更新

**它是什么**：一张"站名 ↔ 官方三字码"的对照表（约 3400 条，含全拼、简拼、所属城市）。
12306 的查询接口认的是三字码（北京南 = `VNP`，上海虹桥 = `AOH`），不认汉字。
你打字联想、界面显示站名、经停站对齐，都要靠这张表。**它已经打进 exe 里**，所以断网也能完成一次查询。

**为什么要更新**：车站会改名、会新开通（例如新站投用、线路调整）。表是 2026-10-10 从官方取的，
超过 90 天设置页会出现一行小字提示。表过期最典型的症状是：**某个站怎么搜都搜不到，或者搜出来三字码对不上**。

**怎么更新**：设置页 →"站点数据"→ 点"更新站点数据"。它会向官方取一次最新表，
**先校验条数够不够，够才替换**；中途断网或数据不全都会保留原来那份并说明原因——
不允许出现"更新失败 → 表坏了 → 应用彻底不可用"。
**换好之后要关掉程序重开一次才生效**，界面会明说这一点。

更新下来的表存在这里（内置那份不动）：`%LOCALAPPDATA%\RouteQuery\stations.json`。

## 本机存了哪些东西

全部在 `%LOCALAPPDATA%\RouteQuery\`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 最多扩展站数、是否看过首次声明、是否检查更新、主题档位 |
| `routes.json` | 常用线路收藏 |
| `history.json` | 最近 30 条查询 |
| `stations.json` | 你手动更新过的站点表（没有这个文件就用 exe 里内置的那份） |
| `session.protected` | 登录状态（DPAPI 密文，只有你这个 Windows 账户能解） |
| `webview2/` | 内嵌登录页自己的缓存 |
| `endpoints.json` | 官方接口路径的缓存（它会改后缀，缓存一次省一次请求） |
| `daily.json` | 当天已发请求数（所以额度不能靠重启刷） |
| `logs/query-日期.log` | 每个官方请求一行，外加异常与"官方给了但被我们摘掉/丢弃"的事件 |

**没有密码、没有验证码、没有 Cookie 明文。** 想彻底清空：设置页点"清空本机数据"（会让你确认），或者直接删掉这个文件夹。

你说"我查不出来了"的时候，把当天那个日志文件发我就够定位了——不用截图，也不用描述。

## 数据是从哪来的

所有车次、余票、票价、经停站、换乘方案都来自 12306 官方查询接口，**只读**。
**取不到就报错，不会用别的方式补一个数给你。** 所以某一格写"官方未给出"、或整屏提示出错时，那是真没拿到，不是系统在猜。
票价和余票随时在变，最终以你下单时 12306 页面显示的为准。

## 出问题先看这里

| 屏幕上写的 | 你该做什么 |
|---|---|
| 请先选定出发站 / 请先选定到达站 | 在框里打几个字。打的名字**只有一个站对得上**时它会自动选上；**对上好几个**（比如打"北京"）就必须点一条——光打字不点，它不替你猜 |
| 出发站与到达站是同一个站 | 换掉其中一个——同站查询官方给不出车次，所以我们不发这个请求 |
| 这个日期不在可查范围内 | 只能查今天起 15 天，换个日期 |
| 连不上网络 / 官方响应有点慢 | 检查这台机器的网络；过一会儿再试 |
| 官方查询暂时不可用，过几分钟再试（不是你的网络问题） | 等几分钟。**反复快点没有用**，这个提示的意思就是"别再点了" |
| 稍等几秒再查询 | 点太快了，等 3 秒 |
| 今日额度已用完 | 等明天。这个上限是故意设的 |
| 官方不认这份登录状态，已清除。请重新登录一次 | 重新登录即可 |
| 票价官方未给出 | 正常。那个接口确实不给票价，去官方页面看 |
| 这趟车在你查的区间已经是全程票了 | 正常提示，不是出错——前后没有更多站可买了 |
| 未确认席别 | 官方从没给过其中两列的中文名，我们照实说不知道，不猜一个标签给你 |
| 官方数据格式变了，这个版本查不了 | 这才真是需要新版：截图或把当天日志发我。**重试不会好** |
| 这台电脑缺少 WebView2 运行时 | 只影响登录；其余功能照常。要装的话去微软官方装 "Microsoft Edge WebView2 Runtime" |

## 系统要求

64 位 Windows 10 或 11。Windows 7 / 8 不支持，32 位系统不支持。
（Windows 10 实机验证还没做过——第一次运行请留意能不能正常打开。）
